- 이미지: `{{png_path}}`
- 결과 파일: `{{json_path}}`
- **파일 도구로 직접 작성한다(UTF-8). 셸 echo·리다이렉트·stdin으로 쓰지 않는다** (PowerShell이 `$`·`\`·한글을 깨뜨린다). BOM·CRLF는 허용된다.
- 다 쓰면 `check --page {{page}}`를 실행하고, 오류가 있으면 JSON을 고쳐 다시 검사한다.

## 전사 규칙
1. 원문 언어를 그대로 유지한다(영어 문제는 영어로, 한국어는 한국어로). 번역·요약·풀이 추가 금지.
2. 수식은 인라인 `$…$`, 독립 수식은 `$$` 를 **독립 줄**에 둔다. 여러 줄 수식은 `$$` 안에서 `\begin{aligned} … \end{aligned}` 를 쓴다. `$`·`{}`·`\left`/`\right`·`\begin`/`\end` 짝을 맞춘다. 문자 달러는 `\$`. 문제문의 **첫 줄**(제목으로 쓰인다)에 `$$` 가 있으면 검사 오류다 — 인라인 `$…$`로 쓰거나 행렬은 둘째 줄부터 둔다. 구간이 `solutions`인 페이지의 항목은 문제가 다시 적혀 있어도 `kind: solution`으로 두고 문제 재진술은 `statement_md`, 풀이는 `solution_md`에 나눠 담는다(재진술이 있으면 조립기가 대응 문제를 찾고, 없으면 그 자체를 문제 노트로 만든다).
3. 러닝 헤더·푸터·쪽번호·워터마크는 생략한다.
4. 문제 번호(`number`)는 인쇄돼 있으면 **반드시** 넣는다. 로마 숫자(`III`)·원문자(`③`)·괄호(`(3)`, `3)`)도 그대로 써도 되며 도구가 `3`으로 정규화한다. 번호가 있는데 `null`로 두면 검사 오류다. 형식은 `12`, `3.4`, `12-1`, `7(a)`. 소문항 (a)(b)(c)/ㄱ)ㄴ)은 `parts` 로 중첩하고 상위 `number` 는 문제 번호만 둔다. `parts[].label` 은 `(a)` 또는 `ㄱ)` 꼴.
5. 인쇄된 제목(시험명·장·절: `2013 기말고사`, `§3.2`, `Chapter 4`)은 `kind: "heading"` 항목으로 두고 `chapter` 에 제목을, `statement_md` 에 표시 텍스트를 쓴다. heading 뒤에서 번호가 1부터 다시 시작해도 된다. 다른 항목의 `chapter` 는 `null` 로 둔다(현재 heading 값과 같을 때만 허용). **페이지에 인쇄되지 않은 장·시험 이름을 만들어 넣으면 검사 오류이며, 검사를 통과시키려고 값을 지어내는 것은 금지다.** 검사 오류가 원문과 충돌하면 고치지 말고 `page_notes`에 적고 사람에게 넘긴다(`skip --reason`).
5-1. 배점이 인쇄돼 있으면(`(10점)`, `(15 pts)`, `[20 points]`) 문제 항목의 `points`에 숫자로 넣고, 소문항 배점은 `parts[].points`에 넣는다. 라벨 텍스트는 원문대로 `statement_md`에 남겨도 된다(조립 시 제목에서 제거되고 중요도 계산에 쓰인다). 없으면 `points`를 생략하거나 `null`.
6. `kind` 선택: `problem`(문제문, 같은 자리에 붙은 풀이가 있으면 `solution_md` 에), `solution`(해설 구간의 해설), `continuation`(앞 페이지 항목의 이어짐), `heading`, `figure_only`(그림만 있고 소속 문제가 앞에 있음), `other`(안내문·정의·표 등 문제가 아닌 본문).
7. 2단 조판이면 `layout: "two-column"` 으로 두고 **열 우선**(왼쪽 열 위→아래, 오른쪽 열 위→아래)으로 읽는다. 한 항목을 페이지 안에서 쪼개지 않는다.
8. 도형·그래프·표 그림은 `figures[]` 에 `bbox_norm: [x0, y0, x1, y1]`(페이지 폭·높이 대비 0~1 비율, 왼쪽 위 원점), `caption`(짧은 제목), `description`(한국어 한 문단: 축·라벨·모양·수치까지 텍스트만 읽는 AI가 재구성할 수 있게). 변이 2 % 미만이거나 페이지의 90 % 이상이면 퇴화로 처리된다.
9. 페이지 끝에서 잘린 항목은 `continues_to_next: true`(마지막 항목에만). 앞 페이지에서 이어진 첫 항목은 `kind: "continuation"` + `continues_from_previous: true`(번호는 이어지는 항목의 번호, 없으면 `null`). 앞 페이지 정보는 아래 컨텍스트를 참고한다.
10. `confidence` 는 0~1 자기 평가(흐릿함·손글씨·복잡한 수식이면 낮게). `page_notes` 에는 특이사항을 적는다. 번호가 2 이상 건너뛰는 것이 인쇄물 자체의 사실이면 `page_notes` 에 `allow-gap` 토큰을 넣는다.
11. `problem` 은 `statement_md` 또는 `parts` 가 비면 안 되고, `solution` 은 어딘가에 해설 텍스트가 있어야 한다. 빈 문자열 대신 항목을 빼라.
