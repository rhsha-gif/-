# Paper lookup

Start from a bounded question or identifier. Select available scholarly tools from inventory and query authoritative databases. Record title, authors, year, DOI/PMID/arXiv ID, URL, query, retrieval date, source and gaps. Validate returned identifiers before follow-up requests.

The API examples in [the reference](references/api-reference.md) are lookup aids; check current official documentation and installed tool schemas before using them. Do not assume a named server is available. If the task requires a particular unavailable server, report blocked.

Metadata, citation counts and abstracts identify candidates; they do not prove a manuscript claim. Inspect the source passage before claiming support. Never infer rights from open access or fabricate citation relationships.

Inside a book repository, follow its project paper-lookup skill, source snapshots and claim-contract checks. Outside a book, return a concise evidence table with limitations; do not create book contracts or load the book workflow.
