# Adaptive Orchestrator v0.6.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add host-aware execution lanes, provider/model-specific official-guidance prompt compilation, shadow routing, and actual model-use tracing while preserving the existing verifier and file-first control plane.

**Architecture:** Introduce focused modules for host context, lane classification, prompt profiles/compiler/lint, shadow selection, and trace events. Extend the existing task/router/runner/CLI pipeline rather than replacing it. The thin hook remains unchanged except for integration instructions; delegated execution must compile and lint a prompt before calling a provider.

**Tech Stack:** Node.js 20+ ESM, native `node:test`, JSON/JSONL file state, Git worktrees, Claude Code CLI, Codex CLI.

## Global Constraints

- Runtime dependencies remain zero.
- No daemon, database, dashboard, nested scheduler, dynamic plugin installation, or in-band prompt-profile self-editing.
- Low-risk direct work uses at most one task and zero external worker calls.
- Bundled work uses at most two task records and one external worker call by default.
- Worker receipts remain claims; deterministic verifier attestations remain completion evidence.
- Prompt profiles must record only official OpenAI or Anthropic source URLs.
- Hidden verifier commands must never be included in worker prompts or prompt manifests.
- Existing v0.4 task files remain valid unless they use newly prohibited unsafe values.
